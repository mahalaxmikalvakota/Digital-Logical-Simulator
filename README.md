# Digital Logic Simulator

A web-based **Digital Logic Simulator** designed to help students understand and experiment with digital logic circuits. The simulator allows users to create logic expressions, generate truth tables, and simplify Boolean expressions using **K-Maps**.

## 🚀 Features

* Create and evaluate Boolean logic expressions
* Generate truth tables automatically
* Boolean expression simplification
* **Karnaugh Map (K-Map)** generation and solving
* Support for common logic gates:

  * AND
  * OR
  * NOT
  * NAND
  * NOR
  * XOR
  * XNOR
* Interactive and user-friendly interface
* Helps students visualize and understand digital logic concepts

## 💡 How It Works

The simulator accepts Boolean logic inputs from the user and processes them to produce the required output.

For example:

```text
A + B
```

represents an OR operation.

```text
A · B
```

represents an AND operation.

The simulator can generate the corresponding truth table and use a **Karnaugh Map** to simplify the Boolean expression.

## 🎯 Objectives

The main objectives of this project are:

* To provide an interactive platform for learning digital logic.
* To simplify Boolean expressions using K-Maps.
* To reduce the difficulty of manually creating truth tables.
* To help students understand logic gates and Boolean algebra through practical experimentation.
